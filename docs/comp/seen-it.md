# Seen It

**Category:** tracking-social
**URL:** Various (multiple apps use this name)
**Platforms:** iOS, Android
**Founded:** Unknown
**Status:** Active but niche

---

## What They Do

Movie and TV tracking app that lets users log what they've watched, maintain want-to-watch lists, rate content, and discover new titles. Functions as a simpler, screen-media-focused alternative to Letterboxd.

## Target Audience

Casual film/TV consumers who want a lightweight watch tracker without Letterboxd's social complexity.

**Overlap with AoA:** Low. Screen media only — no live performances, no venues, no locations. But the tracking UX model (seen/want to see/rating) is the same core mechanic AoA uses.

## Feature Breakdown

| Feature | Details | AoA Overlap |
|---------|---------|-------------|
| Watch tracking | Log movies/TV as seen | Direct — same mechanic |
| Want-to-watch list | Save titles for later | Direct — AoA watchlist |
| Ratings | Rate content | Direct |
| Discovery | Recommendations based on history | Adjacent |

## Business Model

Likely freemium or ad-supported. Niche consumer app.

## Strengths
- Simple, focused tracking UX
- Low barrier to entry

## Weaknesses
- Screen media only — no live events
- Competes with Letterboxd (much larger)
- Limited social features
- No map, no location features

## What AoA Can Learn

### Steal This
- **Simplicity** — The core seen/want-to-see/rate mechanic should be dead simple. Don't over-engineer it

### Differentiation Opportunity
- AoA is Seen It for live theater, with everything Seen It lacks: map, AI, social, progression, education
